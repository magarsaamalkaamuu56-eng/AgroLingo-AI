AgroLingo AI
A beginner-friendly Flask web app prototype for educational maize symptom guidance.
Deploy on Render
Service type: Web Service
Runtime: Python
Build command: pip install -r requirements.txt
Start command: gunicorn app:app
Limitations
This is a rule-based educational prototype, not a trained AI model or certified crop diagnostic tool. Its general symptom guidance should be reviewed against reliable local agricultural sources before real-world use. It does not store user submissions.
